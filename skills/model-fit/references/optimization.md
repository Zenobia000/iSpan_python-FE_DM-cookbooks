# 改善模型



先低成本盤點目前基準的資料版本、切分、指標、推論成本與可重現性。建立或重跑基準前先對齊本輪預算；基準消耗也計入本輪，不能直接比較驗證條件不同的舊分數。

在 research/plan.md 記下本輪目標、候選變因、試驗次數、時間／算力上限、停止條件及採用準則；缺少預算先提出小規模建議，昂貴搜尋前補齊約束。已授權範圍內不逐次重問。

預算明確後，沒有有效基準才由 model-fit 在預算內建立；驗證不成立先由 analysis-review 修正。資源不足以建立可比較基準時記錄阻礙，不開始無法評估的搜尋。

從錯誤切片與資料品質選擇下一步：需要資料洞察用 eda；變換與特徵用 model-fit；候選訓練用 model-fit；公平比較用 analysis-review。每次只改能說清楚的因素，記錄失敗試驗，禁止只保留最佳成績。

到預算或改善門檻停止。依預先授權的採用準則或使用者選擇凍結方案；由 model-fit 進行最終訓練、analysis-review 核對評估與實際模型對應、report 整理產物。最終全資料重訓模型不得冒用原 holdout 分數作為自身未見資料評估。不得反覆以測試集或 public leaderboard 調參。
