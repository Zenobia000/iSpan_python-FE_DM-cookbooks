# 驗證結果



先由資料生成與實際使用情境決定驗證單位：同人／設備／機構須考慮群組隔離，未來預測用時間順序及必要 gap；不能預設 random split。記下方法選擇的實際證據、前提未知處、替代方案與來源。

凍結 split IDs、metric 實作與方向；區分訓練、選模、最終測試。檢查重複個體、目標洩漏、轉換 fit 範圍、外部資料與預測時可得資訊。切分或 metric 改變後建立新比較組，不能直接排列舊分數。

比較簡單基準與候選的效果、變異、錯誤切片和計算成本；依抽樣單位選擇適合的不確定性估計，不將相依 fold 當獨立樣本。小樣本或分布轉移要說明結論範圍。反覆選模造成樂觀偏差時保留獨立最終評估。

核對 run、資料、模型、預測與指標一一對應；最終重訓的模型與選模評估分開標識。提交前按任務契約檢查 ID、順序、shape、schema、有限值、類別／值域與可載入推論。平台成功接受、完成評分、模型表現分別記錄；沒有實跑不可宣稱通過。

結果寫回 research/findings.md 與可追溯的 run 紀錄。analysis-review 負責跨分析結論的獨立質疑，不能取代本技能實際執行的驗證。
