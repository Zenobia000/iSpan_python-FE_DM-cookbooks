# 每輪探勘的開始 回報與接續

開始新一輪 EDA、追查替代解釋或接手既有探索時讀取。AI 承擔研究推論和推薦順序，人類確認問題邊界及需要領域判斷的事項。

## 開始前

先讀使用者目標、既有筆記與本輪需要的證據。有方向歧義才回到 research；不因缺少特定文件阻擋已授權探索。以下流程按任務規模取用，不必每輪完整填寫。

寫下本輪要回答的一個問題：欲補哪個資訊缺口、目前有哪些證據，以及這次比較將增加什麼資訊；有假說時再列支持、反對與待排除的解釋。說明推薦方法與順序的理由，避免只列分析選單。

本輪可為描述、開放探索或假設驗證。開放探索記錄想了解的現象、用途及範圍即可，不編造事前假說；看到資料後提出的假說維持探索身分。沒有 target 也能完成研究，不必先選分類或回歸任務。

## 本輪執行

1. 在 `reports/` 用新檔名保存重要結果；程式放 analysis，參數可留程式內或放 config。
2. 需要時參考 [inquiry 模板](../../eda/templates/inquiry.md) 建立本輪 `eda.md`，在看到結果前記下問題、分析單位、比較與資料範圍；假設驗證另記預測及反證條件。模板提示文字須替換為本輪內容。
3. 依計畫計算與繪圖，保存分母、排除筆數、時間與群組條件。缺少結果或計算失敗時如實保留，不用推測數字補空格。
4. 結果及狀態寫入 research/findings.md，引用本輪證據；不依結果回改 plan 綁定的 hypotheses.md。
5. 新切角標為探索；若準備正式採用新研究設計，更新計畫並核對受影響下游。

保留每輪原始結果；資料、方法或結論改變時，檢查受影響的規則、效益估算與審查，記錄修訂原因。

## 證據依賴與修訂

以輪次或產物路徑作穩定 ID，記錄使用的問題／資料版本、引用證據與必要依賴。引用另一輪結果不代表必須等待該輪所有分支；缺少必要資料或方法不適用時只暫緩受影響分析，無關且已授權的工作繼續。

同份資料的分層、不同方法與不同圖形是共享來源的探索，不能按分支數累計為獨立驗證。綜合判斷引用支持、反對及共用來源，不複製成多份證據。

修訂建立新輪次或新版紀錄，註明取代哪個版本及原因；來源改變時，沿實際依賴標示受影響結論為待重查，重算或重新審查後才恢復使用。無關結論不必重跑，舊結果保留為歷史。這是文件與審查規約，不是自動失效傳播或 DAG 排程功能。

分開記錄執行狀態（完成／失敗／暫緩）、採用決定（採用／暫緩／排除及決定來源）與證據判斷（支持／不支持／不足）。未要求採用決定的描述分析可標不適用；已執行不等於已採用或假說成立，不替人類填寫核准。

## 對人類回報

先回答本輪問題，再交代證據與限制，最後提出有理由的推薦下一步：

```text
本輪回答：目前支持什麼、還不能回答什麼。
依據：效果與不確定性、樣本及群組、圖表和計算路徑。
其他解釋：已排除、尚未排除與資料無法檢查的部分。
推薦下一步：先做哪一項、為何能縮小不確定性、何時停止。
需要你確認：只有會改變問題、資料使用或業務行動的事項。
```

計畫範圍內可以連續執行，不為每張圖重新詢問。若目標改變或要使用新的資料範圍，先呈現修訂後的完整問題並確認。

## 接續與停止

在 `research/handoff.md` 記錄目前問題與計畫版本、資料和程式位置、保留資料的使用情形、已否決解釋及下一步。接手時核對這些證據，不因換 session 就重跑全部分析。

證據已足以支援本次決定、影響低於可接受的業務門檻，或現有資料無法區分主要解釋時，說明理由並收斂。不得僅因未達 p-value 門檻就宣稱沒有影響。

停止時記錄原因：足夠回答、資料不足、資源限制或使用者取消，並列出未解問題。暫停與無法回答不寫成研究成功；既有授權內依停止條件收斂，無需另加結案簽核。
