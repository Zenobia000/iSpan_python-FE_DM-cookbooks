# 圖表的分析與交付契約

準備選圖、繪圖或審查報告圖表時讀取。先定義圖要回答的問題，再選圖型與套件。

## 每張圖要交代什麼

| 項目 | 需要記錄的內容 |
| --- | --- |
| 問題與圖號 | 對應研究問題或假設；以穩定圖號供文字引用 |
| 資料 | 來源版本、開發或驗證範圍、時間、族群與分組 |
| 分母與排除 | 各組樣本及事件數、有效單位數、缺值和排除規則 |
| 變數定義 | 軸、單位、時間窗、類別順序與比較基準 |
| 計算 | 聚合、加權、分箱、平滑、抽樣與排序方式 |
| 不確定性 | 區間表示什麼、如何計算；不適用或無法估計時說明原因 |
| 重現 | analysis/ 程式、config/ 參數與實際繪圖資料表路徑 |
| 解讀 | 一句可支持的結論、主要限制與尚未排除的解釋 |

資訊可分布在圖面、圖說與相連的計算表，不必全部擠進標題。探索抽樣需記錄抽樣方式與種子；圖上抽樣不代表統計估計也使用該子樣本。

## 依問題選圖

| 問題 | 優先考慮 |
| --- | --- |
| 資料分布、偏態或多峰？ | 直方圖、ECDF、箱型圖；必要時補個別點 |
| 群組差距多大？ | 點與區間、分布對照；條形圖使用零基線 |
| 兩個數值如何關聯？ | 散點圖、密度或二維分箱，檢查非線性與群組 |
| 何時改變、是否持續？ | 有正確時間排序的趨勢圖，標明聚合與缺口 |
| 比例由哪些部分組成？ | 分母清楚的比例或堆疊條圖，保留各組總量 |
| 資料品質是否影響結論？ | 缺值率、有效樣本與時間／群組覆蓋圖 |

## 計算與視覺必須一致

報告與圖表使用同一份已核對的統計表。Seaborn 可能自動聚合或估計區間，使用前確認 estimator、errorbar 與重抽樣設定是否符合本題分析單位；不要讓繪圖函式另外產生與正式分析不同的估計。[Seaborn 區間說明](https://seaborn.pydata.org/tutorial/error_bars.html)

區別資料分散程度與估計不確定性；標準差、標準誤與信賴區間不可混標。條形長度需有零基線；折線使用非零基線或對數尺度時清楚標示。相同群組保持一致色彩，比較圖使用可比尺度；不使用裝飾性 3D 扭曲數值。

## 套件與輸出

預設沿用既有 Seaborn／Matplotlib，輸出可連入 Markdown 的 PNG，必要時另存 SVG。互動需求可評估 Plotly 等工具，但先核對專案依賴；新增套件依專案的 pyproject 與 lockfile 流程處理，不讓每個專案任意更換繪圖環境。

套件可以擴充，分母、尺度、統計計算與來源契約保持一致。互動縮放或圖層切換不等於重新估計；新增比較仍需程式執行並保存一輪證據。

互動時區分高亮與篩選，顯示當前範圍及樣本數。篩選後未重算的平滑線、檢定或模型註記須標示原分析範圍，或隱藏並提示重算，不沿用為子群結論。若提供檢視匯出，保存分析 ID、資料版本、列識別與條件；接續前核對版本及列集合，不符就拒絕套用，重算產生新一輪證據。
