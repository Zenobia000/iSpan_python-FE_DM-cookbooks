# 分析專案協作指引

目標清楚就開始，模糊時用 research 協助釐清。依需要選用 eda、model-fit、analysis-review、report，不必走完整流程。已有筆記與授權沿用，不重複要求確認。

目錄最多兩層，檔名與分析方式保持彈性。素材放 materials、數據放 data、程式放 analysis、報告放 reports、模型等產物放 artifacts；config 只放需要抽離的設定。研究文件可合併，模板不必填滿。

原始資料不覆寫。重要結論記下資料、程式、參數與輸出位置；需驗證時避免資料洩漏，區分探索與已驗證結果。敏感資料與憑證不提交，外部發布依使用者授權。
