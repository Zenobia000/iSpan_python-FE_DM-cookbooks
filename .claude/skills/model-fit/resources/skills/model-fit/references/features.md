# 建立特徵



先核對分析單位、預測時點、欄位定義、缺失與資料版本。說明特徵對任務的機制假說、證據、前提與替代做法；缺少直接量測時可協調 eda。不把代理變數當真值或因果證據。

轉換放入可重用的 analysis 程式與 config；保留原始資料。補值、縮放、選特徵、target encoding 等需學習資料的步驟只在各訓練 fold 擬合。聚合與時間窗口不得讀取預測時點之後資料；記錄 train／inference 欄位契約及未知類別處理。

由 analysis-review 指定固定切分，以消融比較新增特徵對相同基準的改善及成本，必要時檢查群組差異。產出 pipeline、欄位來源與可用時間、fit 範圍及驗證結果；未實測的方案明列待驗證，不產生假數字。
