# 方法參考

這裡保留與決策分析架構直接相關的方法來源，供技能設計、領域提問與審查時查閱。

| 文件 | 用途 |
| --- | --- |
| [研究設計與彭明輝著作參考](../../skills/ds-frame/references/research-design.md) | 問題意識、來源比較、假設推論、反證與分析計畫；ds-frame 按需載入 |
| [特徵工程系統化分析指南.pdf](特徵工程系統化分析指南.pdf) | 陌生領域的資料理解、假設生成、特徵工程與視覺化原則 |
| [特徵工程系統化分析指南.docx](特徵工程系統化分析指南.docx) | 同一份指南的可編輯原稿 |

技能實際按需讀取的方法參考與報告骨架，見 [技能參考與模板](../skill-resources.md)。

## PDF 的閱讀切角

| 頁碼 | 主題 |
| --- | --- |
| 5–8 | 問題定義、資料品質、初步探索與假設生成 |
| 8–14 | 特徵處理、洩漏、關係分析與常見誤讀 |
| 15–20 | 依問題選圖、視覺編碼與避免誤導 |

PDF 與白皮書是方法來源，不會因為放在此處就自動載入；研究設計 reference 已由 ds-frame 明確引用。整理成技能可選載的方法文件時，仍須補上適用條件、驗收方式與來源核對；教材中的經驗法則不能直接作為通用分析門檻。

其他課程、範例 notebook、投影片與舊設計素材見 [archive/](../../archive/README.md)。
