# 工作坊課程與驗收設計

> 課時與驗收參考附件。舊教材位置只作歷史對照，不要求保留；技能封裝與執行入口以 [新版 Skill 架構](2026-10-28-skill-based-workshop-design.md) 為準。

本檔是[整體設計](2026-10-28-ai-feature-decision-workshop-design.md)的教學附件。
課時為純教學時間，不含休息；以下為可審查設計，不代表課程程式已完成。

## 1. 12 小時主線

| 單元 | 時間 | 人類任務 | AI 任務與交付 | 舊教材 |
|---|---:|---|---|---|
| W1 決策問題、工作流與環境 | 1h | 用 5 Why／SMART 定義定價任務、可用欄位與指標 | 檢查環境、資料契約、hash、切分與 run manifest | M0、總整 C1 |
| W2 EDA 與品質診斷 | 2h | 判斷零值／缺失／稀有車，完成 G1 | 分佈、分群、共線性與診斷摘要 | M01–M03 |
| W3 特徵假說與防洩漏 | 2.5h | 審查六個假說並否決至少一個不合理提案，完成 G2 | 純衍生與 Fold transformer、特徵字典與測試 | M04–M06 |
| W4 公平比較與篩選 | 2.5h | 解讀配對指標、消融、誤差成本並凍結 G3 | Dummy／Ridge／LightGBM、原始／衍生對照與 OOF | M07、M10 |
| W5 歸因與決策報告 | 2h | 區分關聯／假說／因果，驗收 G4 | OOF SHAP、Dependence、局部錯誤、一次 Holdout 與報告 | M10、二手車總整 |
| W6 分組移轉與答辯 | 2h | 選乳癌或電力，指出主線哪些假設不能搬用 | 用案例 adapter 產出最小對照與限制清單 | M07 或 M08 |
| 合計 | 12h | 主線完整走完一次，延伸以一題分組移轉 | 不要求每組在兩小時重做全部教材 | |

預先環境檢查放課前；沒有 Kaggle 憑證仍可完成二手車全流程。
W5 由 train_eval finalize 負責凍結後重訓與 Holdout；報告腳本唯讀整合。
若簡單模型勝出，以係數／規則解釋取代強制 SHAP，樹模型 SHAP 可保留為具名比較教材。
W6 若延伸資料未取得，改做已提供教學證據的驗證設計答辯，不讓 AI 生成假資料冒充 Kaggle。
助教應在正式課前取得合法延伸資料、驗證 schema，並準備已標記來源與版本的示範產物。

## 2. 6 小時精簡版與 18 小時完整版

6 小時只完成二手車：W1 0.5h、EDA 1h、特徵 1.5h、模型 1.5h、解釋與答辯 1.5h。
使用已核對的欄位契約與預設模型參數；不跑 XGBoost、搜尋或完整 inner-CV 特徵篩選。
仍保留四個人工決策點、Fold 內 fit、OOF 與一次 Holdout。

18 小時以 W1–W5 的 10h 為共同基礎，乳癌 3h、電力 3h、跨案例比較與報告答辯 2h。
三題都跑最小完整流程；事先準備資料與環境。XGBoost 視運算預算選跑，不強制對所有題目搜尋。

## 3. 每階段練習與驗收問題

### G1：資料含義與 EDA

交付資料契約、EDA 報告及三個優先問題。學員必須能回答：

- 為何電動車零排氣量不一定是錯誤？
- 為何缺失熱圖不能證明 MNAR？
- 看到高價低里程的極端車，要補資料、隔離、保留還是刪除？依據是什麼？
- 哪張圖改變了處置，哪張只是重複資訊？

### G2：特徵假說與洩漏

交付特徵登錄、至少一項有理由的否決與程式。可用誘餌題：

- 二手車 `price / mileage` 作為價格模型特徵。
- 以全資料 brand+model 的平均價格補進驗證列。
- 電力預測使用 centered rolling 或未公布的下一小時真值。
- 乳癌 worst/mean 被 AI 稱為病情變化速度。

評分看否決理由，不要求 AI 一開始就犯錯；教師可直接提供上述提案供審查。

### G3：模型決策

交付同 Fold 比較、OOF、消融或汰除候選與凍結決策。要求回答：

- 特徵改善與更換模型改善有沒有分開？
- MAE 正負差值代表什麼？哪些 Fold 倒退？
- 簡單模型相近時，是否值得承擔更多維運成本？
- 為何零 Gain 不能單獨證明特徵無用？
- 時序「下一小時逐步預測」為何不同於「一次預測明天 24 小時」？

### G4：業務轉譯與答辯

交付最終報告，選一筆大誤差案例說明：模型怎麼判、資料缺什麼、哪些結論不能說。
把「里程下降會使成交價上升」改寫為資料支持的關聯，並提出可驗證的下一步。
轉折不穩定時明確拒絕提出硬門檻，也是合格答案。

## 4. 評分規準

| 面向 | 分數 | 驗收證據 |
|---|---:|---|
| 問題、資料契約與來源 | 15 | 目標／單位／可用時間明確、來源可追溯 |
| EDA 到行動 | 15 | 發現有依據、圖表支持處置，不堆圖 |
| 特徵假說與人工審查 | 20 | 公式、邊界、登錄與否決理由 |
| 洩漏防護與公平驗證 | 25 | 固定 Fold、群組／時間隔離、Fold 內 fit、同列比較 |
| 歸因、限制與決策報告 | 15 | 尺度正確、區分關聯／因果、建議可檢驗 |
| 可重現性與維運 | 10 | 腳本、manifest、環境、測試與產物一致 |

資料洩漏、偽造結果、原檔被覆寫或無根據的因果結論，必須修正後才可通過。
沒有提升、沒有可刪特徵、沒有穩定門檻都不扣分；隱瞞失敗或過度宣稱才扣分。

## 5. 後續實作 Definition of Done

### 環境與相容性

- `uv sync --frozen --extra xai` 在支援的專案 Python 版本完成，無系統套件安裝。
- `pyproject.toml`、`uv.lock` 與必要匯出依賴同步；SHAP、NumPy、LightGBM／XGBoost 相容性 smoke test 通過。
- 原始入口與舊 notebook 路徑維持；新增根 README 入口明確標識何時已實作可用。
- 支援無顯示器繪圖，中文顯示或清楚的英文字體後備，缺資料提供明確錯誤。

### 有意義的測試

- 更動驗證集分佈，不改變訓練 Fold 的補值、縮放、編碼與群組統計。
- 更動未來時序值，不改變更早預測起點的特徵；跨設備窗口不混算。
- 依 target_time 檢查 purge，跨 Fold／Holdout 的 proxy group 完全不重疊。
- 時間缺口不被位置 shift 誤當完整一小時；重複時間／DST 未定義時清楚拒絕。
- 零分母、新車／未來年份、未知類別、非有限值、缺目標／缺原檔有明確行為。
- baseline／variant 用相同 row_id 與 Fold，指標的 raw_delta／improvement 方向正確。
- M=1 的 score／SHAP 類別一致；測試 expected value + SHAP 和與模型輸出相符。
- 報告摘要能對回 metrics，不含手寫或虛構的提升；重跑原始資料 hash 不變。

### 整合驗證

- 無 Kaggle 的人工小 fixture 可以跑 CPU smoke test；fixture 明示合成，與真實案例 run 分開。
- 二手車真實資料端到端完成；乳癌與 AEP 在課前下載驗證後各完成最小實跑。
- 記錄實際耗時／記憶體，核對 6／12／18h 課堂安排，不預先保證執行秒數。
- 固定 seed／環境可在合理浮點容差重現；不要求圖片二進位或跨平台模型位元完全相同。
- 所有關鍵產物、指標與圖表相對連結可讀；程式、規範、字典、報告模板符合版本管理策略。
