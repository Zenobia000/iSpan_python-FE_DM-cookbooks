# Hypothread｜問脈 品牌定義

## 名稱與定位

英文名稱 **Hypothread**，中文名稱 **問脈**。Hypothesis（假設）與 thread（脈絡）組合成產品名：讓提問、假設、計算、反證與決策保有可追溯的連接。

對外類別為「資料科學 AI 協作技能套件」，英文為「Research-first data science skills」。主要對象是已使用 Claude Code、Codex 或 OpenCode，想持續探索資料、又重視研究推論與證據品質的資料科學家及分析師。

- 中文主張：**把問題想清楚，讓分析有據可循。**
- 英文主張：**From questions to evidence.**
- 一句介紹：Hypothread 引導 AI 先確認研究問題，再沿著假設、替代解釋與反證推進分析，將資料、程式與決策依據保存在使用者的專案裡。

產品名稱不改變既有的 ds-init、ds-frame 等技能名稱；現有安裝來源與指令繼續使用。Repository 暫時沿用原名稱，對外連結指向輕量 skills 分支。名稱是本次選定的產品識別，不宣稱商標或全球名稱獨占。

## 對外承諾與證據邊界

可以直接介紹的已實作內容：九個技能、三個 CLI 的安裝產物、單一題目初始化、可攜 references、報告模板、OpenCode 指令轉接，以及既有檔案保留。

方法準則要求問題確認、替代解釋、效果量、不確定性、反證及證據交接。將這些描述為工作方法，不宣稱每次模型執行都能正確遵守。

目前有 13 項程式與檔案層級測試；完整模型分析對話及 OpenCode TUI 互動仍未驗收。案例對話標明示意，不寫虛構分析結果、採用客戶、使用者數、提升倍數或實測節省金額。

## 文案語氣

使用「研究問題、推論理由、可比條件、效果與不確定性、下一步」等具體詞。用真實工作場景解釋價值，讓使用者能判斷是否適合自己的題目。

中文 README 是主要入口；英文 README 用於國際社群。英文版明列內附研究指令與骨架主要使用繁體中文，使用者可要求 agent 以偏好的語言討論，不暗示已完成完整多語言驗收。
