# 版型 W：白底正黑體（定稿）

風格字串的權威版本內嵌在 [`../build_slides.py`](../build_slides.py) 的 `STYLE` 常數，
這份是給人讀的說明。兩邊若不一致，以程式為準。

## 風格字串

```
一張 16:9 教學投影片。純白色背景，乾淨無底紋無漸層。
字體規定：全頁所有文字，包含中文、英文與阿拉伯數字，一律使用無襯線黑體，
類似思源黑體或 Helvetica 的字形。標題、內文、標籤、數字全部都是無襯線。
絕對不要出現襯線體、明體、宋體、楷體或任何有裝飾筆畫的字形，標題也不例外。
主文字為近黑色，次要說明為中灰色，分隔線與線框為淺灰色。
標題靠左，字重明顯較粗，標題下方一條淺灰色水平細線橫貫內容區寬度。
強調只用兩種手段：把字加粗，或在字下方加一條粗的黑色底線。
需要標示錯誤時才用朱紅色，其餘一律黑白灰。
版面留白充足，元素之間對齊嚴謹，整體像印刷品而不是網頁。
邊界嚴格：上下各留白約畫面高度的百分之九，左右各留白約畫面寬度的百分之七，
所有內容的左邊界對齊同一條垂直線，多欄並排時欄距一致、最左欄貼齊左邊界、最右欄貼齊右邊界。
```

## 邊界規格

畫面比例 16:9。以畫面寬 W、高 H 計：

| 區域 | 位置 |
| :--- | :--- |
| 上留白 | H 的 9%，標題頂端不得高於此線 |
| 下留白 | H 的 9%，任何元素不得低於此線 |
| 左右留白 | 各 W 的 7%，所有內容左邊界對齊同一條垂直線 |
| 標題區 | 上留白之下，高約 H 的 14% |
| 標題分隔線 | 標題區下緣，長度等於內容區寬度 |
| 內容區 | 分隔線下方 H 的 4%，到下留白為止 |

## 不要出現的東西

- **右下角不要頁碼，不要章名標籤，不要任何頁尾。** 頁序由檔名管理。
- 不要來源、不要公司名或署名、不要浮水印。
- 不要自行加入百分比或統計數字，數字一律由內容描述指定。
- 不要藍色。錯誤標示用朱紅，其餘黑白灰。

## 產出尺寸

gpt-image-2 只有 1024x1024、1536x1024、1024x1536。
生成 1536x1024 之後由 `build_slides.py` 的 `to_16x9()` 左右補上角落取樣色擴成 1820x1024，
底色是純白，接縫不可見，也不裁切內容。

## 停用的版型

- 版型 C 牛皮紙手繪（莫蘭迪）：試過三個方向後未採用。
- 版型 M 深海軍藍襯線（顧問簡報）：採用過一輪，後改為白底無襯線。
