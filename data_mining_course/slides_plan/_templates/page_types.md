# 頁型與節奏

同一種密度從頭鋪到尾，等於整堂課用同一個語速講話。這份定義七種頁型，
每種有自己的資訊量與用途；排課時交錯使用，讓節奏有起伏。

風格見 [`style_W.md`](style_W.md)，術語見 [`glossary.md`](glossary.md)。

## 七種頁型

| 頁型 | 密度 | 主視覺 | 什麼時候用 |
| :--- | :--- | :--- | :--- |
| A 過場 | 極疏 | 無，純留白 | 開章、換段落。給學員一個呼吸的節點 |
| B 金句 | 極疏 | 無，一句話撐滿 | 鐵律、第一原理、要背下來的那句 |
| G 概念圖 | 中 | **一張機制圖佔版面六成以上** | 這門課的主力頁型。講清楚一個東西怎麼運作 |
| C 圖比較 | 密 | 3 到 4 個並排的小機制圖 | 方法取捨。每個選項各畫一張小圖，不是列文字欄位 |
| D 步驟 | 中 | 同一張圖逐頁長出來 | 需要慢慢講的機制。連續 2 到 4 頁 |
| E 對照 | 中密 | 錯與對兩張圖並排，附數字 | 反例、洩漏、常見誤解 |
| F 速查 | 密 | 卡片與列表，可以沒有圖 | 器層、API、隨堂帶著走的表 |

## 最重要的一條：每頁要有主視覺

先前的版本把「圓框小圖示加欄位加文字」當成視覺，那本質上還是表格，
整份翻起來就是一張張表。參考的顧問簡報裡，主體其實都是圖——管線、曲線、時間軸——
文字是在標註圖。

所以每一頁（A 與 B 除外）都要先想清楚一件事：**這頁的機制圖長什麼樣。**
想不出圖，代表這頁的內容其實是清單，該併到 F 速查頁，不該單獨成頁。

判準：把所有文字遮起來，圖還看得懂在講什麼，這頁才成立。

## 排列規則

1. **不要連續兩頁 C。** 兩頁高密度連著上，第二頁沒人在看。
2. **D 一定連續出現**，2 到 4 頁一組。拆一步就翻一頁，畫面延續、只加東西不重畫。
3. **每章開頭一頁 A，結尾一頁 F。** 中間才是 B、C、D、E、G 的組合。
4. **B 一章最多一頁。** 金句多了就不是金句。
5. 密度節奏大致是：疏 → 極疏 → 中 → 密 → 中 → 中 → 中 → 中密 → 密。
6. **G 是主力。** 一章八到九頁裡，G 加 D 至少要佔四頁。C 最多兩頁。

## 從第 4 章實作學到的四條

這四條是實際生完一章、逐頁檢查之後才知道的，寫在這裡免得每章重踩。

**一、D 型的場景敘述要逐字重複。**
一開始每頁各描述一次畫面，模型就各畫各的：第 5 頁畫五列資料，
第 6 頁自己換成另一份資料還多長一欄。改成把場景抽成一段固定文字，
三頁都貼同一段，只在後兩頁補「這一頁多什麼」，連續性才成立。

**二、顏色不能只寫「不要用」，要指定「用什麼」。**
提示詞寫了「不要使用藍色」，錯與對的對照頁還是整片藍——模型對
「正確等於藍色」有很強的預設，禁止詞壓不過去。改成明寫
「左半只用朱紅，右半只用黑色與深灰」之後就對了。

**三、示範數字要能當場驗算。**
第 7 頁排除第一列之後，BMW 只剩第三列的 35，所以均值就是 35.0。
數字對得起來，學員才能自己驗證機制。所以資料要刻意設計成同一類別出現兩次以上，
否則群平均等於自己的值，講不出重點。

**四、速查該獨立成頁，不要塞在別頁底部。**
為了壓頁數把 API 卡片塞進對照頁底部，結果那三個方框跟上面的機制圖沒有關係，
看起來是硬塞的。寧可多一頁。

## 逐頁校對之後補的三條

103 頁全部看過一遍，除了前四條之外還發現這些。

**五、A 與 B 頁不能給「左上角標題」的指令。**
風格字串一律要求標題靠左上，但這兩種頁型的設計是「整頁只有一句、置中」。
兩個指令打架時，模型會照放左上，然後**自己在中央編一句新的**——
第 0 章一度出現「模型不是算出來的，是校出來的」這種我從沒寫過的句子。
`build_slides.py` 已依頁型分流，A/B 頁改成「整頁只有這一句，不得出現第二個句子」。

**六、留白處模型會自己填。**
反捏造那段要明講「不要自己補我沒指定的標語，空白處就讓它留白」。

**七、否定詞會被吃掉。**
「選擇沒放進 Pipeline」被渲染成「遴擇法放進 Pipeline」——漏了「沒」，
「選」還變成「遴」，一個陷阱因此變成在描述正確做法。
陷阱類文字要寫成不依賴單一否定詞就能懂的句子，例如「忘了把選擇放進 Pipeline」，
並在描述末尾補一句「這三句都是錯誤示範，文字要完整不可省略任何一個字」。

**八、顏色禁令對「強調」語意無效。**
寫了「不要使用藍色」，強調框與底線還是會變藍。要逐一指定
「這個框必須是黑色，不可以是藍色」才壓得住。

## D 型（步驟）怎麼拆

拆的是**機制**，不是流程清單。流程清單一頁列五步就好，那是 C。
會拆成 D 的只有兩種：學員一定會做錯的，和光看結果無法還原過程的。

第 4 章的 Target encoding 洩漏就是範例，三頁共用同一張五列資料表：

- 第一步：正常情況怎麼算，編碼值欄留空。
- 第二步：同一張表，第一列加紅框、加一條繞回自己的紅色箭頭，填入 33.5。
- 第三步：同一張表，第一列變灰被排除，其餘四列拉箭頭到均價表，BMW 均價變成 35.0。

三頁只有差異在動，骨架不動。這是 D 型跟「三張不同的圖」的差別。
