# 特徵工程課的宗旨

這份是課綱的憲法，投影片和 notebook 都要對得回這裡。

## 這門課到底在教什麼

來的人已經會 Python、前後端、資料庫、機器學習，手上也已經有 Copilot、ChatGPT、Claude。會不會寫 `sklearn` 的 API 早就不是瓶頸了。

所以這門課補的是另一件事：資料丟進模型之前該變成什麼樣子、為什麼；以及 AI 幫你寫完轉換之後，人還要盯什麼。

分工是這樣：AI 可以提假設、可以寫轉換，人負責理由、SMART、先切再轉、洩漏這四件事。好的特徵仍然要能講人話，embedding 可以用，但你要說得出它代表什麼。

課程有兩條線，分開教，不要混成一本：

- 資料分析這條線靠領域知識驅動，處理缺值、編碼、聚合、時間窗，假設從領域來。
- AI 前處理這條線處理文字、圖片、聲音、影片怎麼理解、清理、導入成張量、接到訓練。

上課順序是先工具後整合。M1 和 M2 預設交給學員自學。

## 教材分兩層

第一層是講義，也就是每章的 overview：這個模組有哪些工具、什麼時候用、AI 能代勞什麼、人必須盯什麼。

第二層是小 notebook：一個技法（或者關係很近的一組），配一份真實資料，從頭繞完一次。

## 思考順序

總整會完整走一遍，各模組的講義會點到自己落在哪一步。

1. 這次要決定什麼。
2. 用 5 Why 挖到資料量得到的真因。
3. 用 SMART 篩：量得到、對這次決策有用、能講人話。
4. 找出領域上的理由，靠經驗或讓 AI 當領域助理。
5. 看資料對不對得上，對不上就自己造，或把它記成限制。
6. 到這裡才選技法，然後驗收：人話、洩漏、拿掉它會怎樣。

不要用商業 MVC 或五塊思考法。細節見 [`capstone/slides/C1_宗旨與心智模型.md`](../capstone/slides/C1_宗旨與心智模型.md)。

## 涵蓋範圍

表格特徵工程的部分包含缺值與異常、編碼與縮放、聚合與時間窗、洩漏、特徵選擇。

多模態與訓練前處理的部分是理解、清理、導入、接到模型這一條龍，包含影片，也包含 LoRA 的最小 demo。

探勘落地的部分講樹重要性、端到端流程、分群，用的是真實客戶資料。關聯規則只上一小段，用來對照現代推薦是怎麼做的。

最後是總整：英國二手車加上前面的心法。

不涵蓋的東西：AutoML 平台評分、從零教 pandas、把 Apriori 當成現代推薦的主線。
