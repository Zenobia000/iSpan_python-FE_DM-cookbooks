# 特徵工程課：宗旨

這份是課綱的憲法。投影片與 notebook 都對這裡。

## 這門課在教什麼（2026）

學員已會 Python、前後端、資料庫、機器學習，**手上已有 Copilot、ChatGPT、Claude**。會寫 `sklearn` API 不再是瓶頸。

這門課補的是：**丟進模型前，資料要變成什麼、為什麼**；以及 AI 寫出轉換之後，人要盯什麼。

- AI 會提出假設、會寫轉換；**人負責 Why、SMART、先切再轉、洩漏**。
- 好特徵仍要能講人話。embedding 可以用，但你要說它代表什麼。
- 兩條線分開教、不要混一本：
  - **數據分析／domain driven**：缺值、編碼、聚合、時序窗——假設從領域來。
  - **AI 細部前處理**：文字／圖／聲／影怎麼理解、清理、導入成張量、接到訓練。

上課順序：**先工具、後整合。** M1／M2 預設前情自學。

## 教材兩層

| 層 | 做什麼 |
|---|---|
| 講義／章 overview | 這個模組有哪些工具、何時用；AI 能代勞什麼、人必須盯什麼 |
| 小 notebook | 一個技法（或緊密對照）+ **一份真實資料**繞完 |

## 思考順序（總整走完；各模組講義會點到對應那一步）

1. 這次要決定什麼。
2. 用 **5 Why** 挖到資料量得到的真因。
3. **SMART**：量得到、對這次決策有用、能講人話。
4. domain（經驗或 AI 當領域助理）。
5. 資料對不對得上；對不上就創造，或記限制。
6. 才選技法。驗收：人話、洩漏、拿掉它模型會怎樣。

不要用「商業 MVC」「五塊思考法」。細節見 [`capstone/slides/C1_宗旨與心智模型.md`](../capstone/slides/C1_宗旨與心智模型.md)。

## 涵蓋

- 表格 FE：缺值與異常、編碼與縮放、聚合與時間窗、洩漏、特徵選擇。
- 多模態與訓練前處理：理解 → 清理 → 導入 → 接到模型（含影片、LoRA 最小 demo）。
- 探勘落地：樹重要性、端到端、分群（真實客戶資料）；關聯規則只上一小段對照現代推薦。
- 最後總整：英國二手車 + 心法。

不涵蓋：AutoML 平台評分、從零教 Pandas、把 Apriori 當成現代推薦主線。
